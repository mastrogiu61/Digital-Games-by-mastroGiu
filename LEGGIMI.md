# Le mie prime parole in italiano

by mastroGiu

## Prova subito
Apri `index.html` con Chrome o Edge su Windows, oppure con Chrome su Chromebook. Non servono installazione, account, librerie o servizi a pagamento. Tutto il gioco è contenuto nel file HTML, con CSS, JavaScript e illustrazioni incorporate.

1. Scegli un'attività.
2. Tocca le carte per ascoltare e ripetere.
3. Premi “Giochiamo!” e scegli una risposta, oppure trova le coppie nel memory.
4. Ripeti o passa all'attività successiva.

Le cinque attività restano sempre accessibili. Ogni risposta corretta o coppia trovata assegna 10 punti una sola volta; massimo 340 punti. Nessuna penalizzazione per gli errori o le ripetizioni. I progressi rimangono nella scheda aperta e si azzerano ricaricando la pagina. Non vengono raccolti dati personali.

La sintesi vocale usa la Web Speech API del browser. La disponibilità e la qualità della voce italiana dipendono dal sistema operativo e dalle impostazioni del dispositivo; alcune voci richiedono Internet. Se l'audio non funziona, verifica il volume e la disponibilità di una voce italiana o leggi le parole insieme allo studente. Il gioco funziona anche senza audio.

## Pubblicazione gratuita su GitHub Pages
1. Crea un repository pubblico su GitHub, oppure usa un repository esistente.
2. Carica `index.html` nella cartella principale del repository e conferma il commit.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, ramo **main**, cartella **/ (root)** e premi **Save**.
5. Attendi la pubblicazione: GitHub mostrerà il link del sito nella stessa pagina.
6. Prova il link in una finestra privata: il gioco deve aprirsi senza login.

Non servono build, chiavi API o dominio a pagamento. Tutti i percorsi sono compatibili anche con un sito GitHub Pages ospitato sotto il nome di un repository.

## Condivisione su Google Classroom
Apri il corso, scegli **Lavori del corso → Crea → Materiale** (oppure **Compito**) e aggiungi il link GitHub Pages tramite **Aggiungi → Link**. Il gioco non richiede una registrazione dello studente; l'accesso al corso Classroom segue le impostazioni della scuola. Il punteggio del gioco non viene inviato a Classroom.

## Suggerimento didattico
Usa il percorso per 25–35 minuti, anche in più incontri. Accompagna ogni parola con un gesto o un oggetto reale. Incoraggia la ripetizione orale senza obbligare lo studente a parlare subito. L'inglese è un supporto breve; per “Mi chiamo…” invita lo studente a completare oralmente con il proprio nome.

## Verifica della prima versione
Controllati sintassi JavaScript, completamento delle cinque attività, risposte errate senza penalità, coppie memory, massimo 340 punti e ripetizioni senza accumulare punti duplicati tramite simulazione degli eventi. Non è stata effettuata una prova visiva in un browser reale né una prova audio su Windows/Chromebook: verificare questi aspetti sul dispositivo prima della lezione.
